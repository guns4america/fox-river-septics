# Fox River Septics — Website Redesign

A responsive single-page website prototype for Fox River Septics LLC.

## Files
- `index.html` — homepage structure and SEO metadata
- `styles.css` — responsive visual design
- `script.js` — mobile menu and contact interactions

## Preview
Open `index.html` in a browser or serve the directory with a static web server.

## Before launch
- Obtain the business owner's approval for copy, details, and branding.
- Replace illustrative imagery with licensed/approved real project photography.
- Check and confirm address, phone, email, service territory and licensing claims.
- Set up a working contact-form backend or use the included email-based estimate interaction.
- Update canonical URL and structured data if hosted on another domain.
- Test on real mobile devices and verify accessibility, performance and SEO.
- Do not point the live business domain here until reviewed and approved.

This repo is not a live production deployment.
